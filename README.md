# Jarcar Motors — Frontend

Proyecto de frontend desarrollado con **React, TypeScript y Vite** para Jarcar Motors.

## Requisitos

- Node.js 22
- npm
- Para subir al repositorio: Git y [GitHub CLI](https://cli.github.com/)

## Desarrollo local

```bash
npm install
npm run dev
```

## Compilación

```bash
npm run build
```

## Despliegue en Vercel

- Framework: Vite
- Root Directory: `.`
- Build Command: `npm run build`
- Output Directory: `dist`
- La configuración de las rutas está en `vercel.json`.

## Código y recursos

- `src/`: aplicación React, páginas y componentes
- `public/jarcar-v3/vehicles/`: fotografías optimizadas del inventario
- `public/jarcar-v4/`: recursos de marca y diseños editoriales
- `GUIA_DESPLIEGUE_VERCEL.md`: guía de despliegue y verificaciones

**Importante:** el inventario incluido es una copia local, no una sincronización en tiempo real. Antes de usar el sitio como presencia oficial, confirmar datos, disponibilidad y permisos sobre los materiales.
