# Jarcar Motors — Frontend

Sitio web automotriz desarrollado con React, TypeScript y Vite.

## Desarrollo

```bash
npm install
npm run dev
```

## Vercel

Build: `npm run build` · Output: `dist` · Framework: Vite.

La web usa un inventario local, no conectado a disponibilidad en tiempo real. Antes de su publicación comercial deben validarse precios, disponibilidad y material fotográfico.
